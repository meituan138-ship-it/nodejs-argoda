# A 股全市场 LightGBM 选股（只做多、可执行版本）

## 设置（规则在看结果之前定好）
- **数据**：腾讯行情接口，2012-01 → 2026-09。收益用后复权价计算，成交额和股价水平用不复权价。共 5460 只股票，**包括已退市股票**（如乐视网、长航油运、银基发展），所以回测没有幸存者偏差。
- **股票池**：每周决策时，要求股票上市超过 120 个交易日、当天有成交、20 日平均成交额 ≥ 2000 万元。平均每周约 3400 只。
- **成交时点**：每周最后一个交易日收盘后出信号，**下一个交易日开盘买入**，下次调仓日的次日开盘卖出。
- **特征**：共 73 个，只用价量数据：多周期收益、日内/隔夜收益、波动率、成交额及其变化、Amihud 非流动性、最大/最小日收益、偏度、振幅、52 周高低点距离、近期涨停/跌停次数、股价水平、均线偏离、beta、特质波动、量价相关、上市年限、所属板块；以及上述特征的横截面排名和 4 个大盘状态变量。
- **模型**：LightGBM 300 棵树、2 个种子。每季度重训一次，训练数据从 2013 年开始，训练集与测试集之间留 2 周间隔。样本外测试期 2016-01 → 2026-09，共 548 周。
- **组合**：每周等权持有预测最好的 50 只（或 100 只），**只做多**。
- **可交易性约束**：开盘涨停的买不进；开盘跌停或停牌的卖不出，只能继续持有。另外用一条保守规则处理 ST 股：开盘跳空 ≥ +4.5% 且开盘价就是最高价时视为买不进，≤ −4.5% 且开盘价就是最低价时视为卖不出。
- **成本**：佣金每边 0.025%；卖出印花税 0.1%（2023-08-28 起 0.05%）；滑点每边 0.1%，压力测试用 0.2%。

| LightGBM 前 100 只 | 23.1% | 0.95 | −30.9% |
| LightGBM 前 50 只，滑点 0.2% | 16.1% | 0.71 | −35.6% |
| LightGBM 前 50 只，只选日成交额 > 1 亿元的股票 | 14.3% | 0.65 | −41.1% |
| 随机选 50 只（对照） | −15.0%（扣费前 −0.1%） | −0.53 | −86% |
| 小市值前 50 只 | −5.5% | −0.18 | −68% |
| 1 月反转前 50 只 | −15.2% | −0.49 | −87% |

| 中证 1000 | −1.5% | 0.07 | −53% |

- **预测能力**：预测排名和下周实际收益排名的周均相关（Rank IC）为 **0.122，t 值 19.4**；2016–2026 年每年都在 0.088–0.170 之间，没有一年失效。
- **相对中证 1000 的年化超额收益 23.7%（t 值 4.4）**。11 年里只有 2019 年跑输（−2.9%）。
- 剔除收益最高的 1% 周（例如 2024-02-19 那周小盘股暴跌后的反弹 +28.5%）后，年化仍有 14.8%。

**LightGBM 前 50 只的逐年收益（扣费后）**：2016 +72.4%、2017 +3.4%、2018 +29.2%、2019 +25.2%、2020 +43.3%、2021 +24.1%、2022 +6.6%、2023 −3.3%、2024 +10.2%、2025 +53.7%、2026（1–9 月）+15.0%。

## 必须注意
1. **成本和成交最关键**：每周约 70% 的仓位要换手。滑点从 0.1% 升到 0.2%，年化就从 25% 掉到 16%。只做日成交额超过 1 亿元的股票时年化是 14%。**真实滑点必须用小资金实盘来验证。**
2. **收益集中在小票**：选出来的股票，日成交额中位数只有约 3000 万元。资金一大（比如超过几百万元）就会推动股价，回测收益会下降。
3. **没有识别 ST 股票**：只靠跳空规则保守处理。退市股票的真实下跌已包含在数据里。
4. **基准是价格指数**：沪深 300、中证 500、中证 1000 都不含分红，大约少算每年 1–2%。
5. **免费数据有缺口**：约有 200–300 个代码因接口限流没下载到，这部分是否有偏差尚未核查。
6. **历史不代表未来**：A 股规则会变，比如 2024 年后监管收紧、打击小盘股投机。量化私募也在做同样的事，这类优势可能衰减。

